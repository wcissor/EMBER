# RUTA agritech reel

A 36–45 s vertical reel about how farming is changing in the open field: laser weeding, farm drones, solar cattle collars and free satellite imagery. It comes in English with three hooks and ends on a RUTA end card, built with Remotion and TypeScript, ElevenLabs and ffmpeg.

Azerbaijani versions were built and checked too. RUTA only needs English, so they are not delivered, but every script still takes `az` (for example `scripts/render.sh az`, `python3 scripts/assemble.py az-A`).

| Variant | Hook | Lines |
|---|---|---|
| A | Indoor farms raised billions; many of the biggest went bust | H1, B1, B2, B3, B4, B5, B6, B7, B8 |
| B | A robot that burns weeds with lasers | H2, B1b, B3, B4, B5, B6, B7, B8 |
| C | Cows that don't need fences | H3, B4s, B1b, B2, B3, B5, B6, B7, B8 |

## Deliverables (`out/`)

- `ruta-agritech-en-{A|B|C}.mp4`: voice, sound effects and a placeholder music bed. Not in git (54–66 MB each); rebuild below.
- `ruta-agritech-en-{A|B|C}-nomusic.mp4`: voice and sound effects, for adding a track in Instagram.
- `cover-en.png`: the hook claim in big type, inside the middle 1080×1440.
- `captions-en-{A|B|C}.srt`
- `posting.md`: captions, hashtags, the first comment with sources, and the test plan.
- `sources.md`, `licenses/`: copies of the top-level files.
- `qa/report.md`: the 12 checks, with stills, contact sheets and loop strips.

## Where things live

- `src/config.ts`: every caption and on-screen string in both languages, and the word anchors that time the cuts.
- `src/scenes.tsx`: one scene per line.
- `src/drawings.tsx`: crosshairs, the collar inset, the dotted fence, the globe, the map zoom and the capture frame.
- `src/EndCard.tsx`: the end card. The closing shot closes onto its horizon, the line becomes a short olive rule, and the RUTA logo rises above it (`END` in `src/timeline.json`, 1.8 s).
- `src/components.tsx`, `src/theme.ts`, `src/layout.ts`, `src/motion.ts`: the design system (colour, type, safe box, easing).
- `src/timeline.json`: beat lengths and word timings, generated by `audio/build_timeline.py`.
- `vo/`:
  - `vo/script-{lang}.json`: the exact text sent to ElevenLabs.
  - `vo/takes/`: both takes with their Scribe word timings.
  - `vo/audition/`: the voice audition.
- `sfx/raw/`: ElevenLabs sound effects, two takes each.
- `audio/build_audio.py`: voice placement, effect cues, the music placeholder, mixing and mastering.
- `scripts/footage.py`: trims, grades and crops the licensed Adobe Stock clips to 1080×1920 proxies.
- `scripts/maps.py`, `scripts/s2_crop.py`, `scripts/s2_vertical.py`: the globe, the map and the Sentinel-2 images.
- `licenses/`: Adobe Stock records, imagery and data credits, the font licence, ElevenLabs.
- `sources.md`: every number with its source and the exact quote. `shotlist.md`: the shots, as planned and as built.

## Rebuild

The licensed footage is not in git. Re-download the clips from the Adobe Stock account into `footage/src/`; the IDs are in `licenses/adobe-stock/records.md`.

```sh
npm install
python3 scripts/footage.py                    # graded 1080x1920 proxies -> public/footage/
.venv/bin/python -I scripts/maps.py           # globe and maps (needs rasterio and numpy in .venv)
python3 audio/make_lines.py                   # one wav per line from the chosen takes
python3 audio/build_timeline.py               # src/timeline.json
npx remotion bundle src/index.ts --out-dir build/bundle
scripts/render.sh                             # every beat, muted -> out/beats/
python3 audio/build_audio.py                  # audio/mix/*.wav, -14 LUFS
python3 scripts/assemble.py                   # out/ruta-agritech-*.mp4
python3 scripts/srt.py                        # captions
ffmpeg -ss 2.5 -i public/footage/H1-a.mp4 -frames:v 1 -q:v 2 public/img/cover-h1a.jpg   # cover background
npx remotion still build/bundle Cover out/cover-en.png --props='{"lang":"en"}'
# QA
python3 -I scripts/qa.py
npx remotion bundle src/index.ts --out-dir build/bundle-qa && scripts/textonly.sh && python3 -I scripts/qa_text.py
python3 scripts/qa_stills.py && python3 scripts/report.py
```

Each beat is rendered once and reused by every variant that has it. Variants are joined with the concat demuxer, so changing one line means re-rendering only that beat (`scripts/rerender.sh en-B2`) and re-running `assemble.py`.

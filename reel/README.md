# AgLink by RUTA: 30-second reel

A vertical reel (1080×1920, 30 fps) explaining AgLink, built with Remotion and TypeScript, ElevenLabs and ffmpeg.

## Deliverables (`out/`)

- `ruta-aglink-reel.mp4`: voice, sound effects and music
- `ruta-aglink-reel-nomusic.mp4`: voice and sound effects, for adding a track from Instagram's library
- `captions.srt`
- `cover.png`: the S3 frame with "AgLink"; it sits inside the middle 1080×1440 for the grid crop
- `qa/`: stills per scene with the safe box, the sound-off contact sheet, `checks.json`, and `report.md`

## Where things live

- `src/config.ts`: every string (script, captions, labels, end card)
- `src/theme.ts`: colours and fonts
- `src/layout.ts`: safe box, grid and all positions
- `src/motion.ts`: easing and timing tokens
- `src/timeline.json`: frame-exact scene cuts, word timings and event times, generated by `audio/build_timeline.py`
- `audio/build_audio.py`: voice placement, sound effects, the music pulse, the mix and the master
- `vo/`, `sfx/raw/`: the ElevenLabs takes and sound effects that were used
- `public/`: fonts, the RUTA logo (cut out from the website file), the duotone opening photo

## Rebuild

```sh
npm install
python3 audio/build_timeline.py      # needs vo/takes/take-a.mp3 and its transcript
python3 audio/build_audio.py         # stems, mix.wav, mix-nomusic.wav
node --no-warnings scripts/make-srt.mjs
./scripts/render.sh                  # per-scene renders, concat, mux, cover
python3 scripts/qa.py && python3 scripts/report.py
```

To change the end card, add the website or handle to `END_CARD.handle` in `src/config.ts` and run `./scripts/render.sh`.
Changing wording that is spoken needs a new voice take, then the full rebuild above.
